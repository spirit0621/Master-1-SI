## 💡 Bonnes Pratiques de Documentation
1. Chaque document Markdown dispose d'un **sommaire interactif cliquable** en en-tête.
2. Les schémas d'architecture privilégient le format **Mermaid.js** ou **SVG vectoriel** pour garantir un affichage immédiat sans dépendances externes.
3. Les structures applicatives complexes sont découpées selon le standard du **C4 Model** (Context, Container, Component, Code).
